## 📌 Project Overview

This repository contains all six core deliverables completed for Week 2 of the Data Analytics Internship at Bluestock Fintech:

1. **Stock Market Fundamentals:** Comprehensive summary of core market concepts.
2. **Financial Statement Analysis:** A structured framework for evaluating listed companies.
3. **REST API Data Pipeline:** Python automation to fetch API data and convert JSON to CSV.
4. **Git & GitHub Workflow:** Documentation of version control practices and commands.
5. **Software Data-Flow Architecture:** Data architecture and system flow diagram.
6. **Indian FinTech Industry Report:** Market analysis and overview of the Indian FinTech landscape.

> ⚠️ **Disclaimer:** Educational project only. This is not investment advice. Financial metrics have been compiled based on public financial reports and templates.
